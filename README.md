# Student Management Flask API

A RESTful API developed using **Python and Flask** to manage student records efficiently. This project demonstrates backend development concepts, API creation, and CRUD operations.

### Features
- Add new student records
- Retrieve student information
- Update existing student details
- Delete student records
- RESTful API endpoints
- JSON-based request and response handling

### Technologies Used
- Python
- Flask
- REST API
- JSON

### Purpose
This project is developed to practice Python Flask API development and understand how RESTful APIs work in real-world applications.
